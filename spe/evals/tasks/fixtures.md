Shared fixture project for all tasks: "triage", a Claude agent that reads incoming support tickets for a SaaS company, assigns a category (billing, bug, how-to, account, outage) and a priority (P1 to P4), and drafts a first reply. The eval set is 40 historical tickets with reference labels from the support lead. Configurations so far: A = Sonnet 5.5 with a 30-line prompt and 6 tools, B = A with a 12-line prompt, C = B with tools merged to 3, D = C on Haiku 5.5.
