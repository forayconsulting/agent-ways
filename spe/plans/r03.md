|---|---|
| An E2E worker writes outside its fixture | The prompt confines it. The escape scan voids the trial. Fixtures live under `/tmp/spe-e2e/r03/` only |
| E2E workers loop or run long | A 20-tool-call cap in the prompt. Halt the run if it passes 120 minutes |
